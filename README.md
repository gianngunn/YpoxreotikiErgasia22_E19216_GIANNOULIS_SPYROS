
# Λειτουργίες συστήματος

- /register

    Εδώ ο χρήστης κάνει εγραφή. Σε περίπτωση σφάλματος εμφανίζεται μήνυμα.

- /login

  Εδώ ο χρήστης κάνει είσοδο στο σύστημα. Σε περίπτωση σφάλματος εμφανίζεται μήνυμα.

- /createNote
  
   Εδώ ο χρήστης δημιουργεί μια σημείωση στο σύστημα. Σε περίπτωση σφάλματος εμφανίζεται μήνυμα.
   
- /getNoteWithTitle/(write the title here)
   
    Εδώ ο χρήστης κάνει αναζήτηση με βάση τον τίτλο της σημείωσης στο σύστημα. Σε περίπτωση σφάλματος εμφανίζεται μήνυμα.
    
- /getNoteWithKeyword/(write the keyword here)

    Εδώ ο χρήστης κάνει αναζήτηση με βάση μια λέξη κλειδί της σημείωσης στο σύστημα. Σε περίπτωση σφάλματος εμφανίζεται μήνυμα.
  
- /editNote/(write the title of the note you want to edit here)

  Εδώ ο χρήστης κάνει τροποποίηση με βάση τον τίτλο της σημείωσης στο σύστημα. Σε περίπτωση σφάλματος εμφανίζεται μήνυμα.

- /deleteNote/(write the title of the note you want to delete here)

  Εδώ ο χρήστης διαγράφει με βάση τον τίτλο της σημείωσης στο σύστημα. Σε περίπτωση σφάλματος εμφανίζεται μήνυμα.

- /getAllNotes/(write asc or des for the cronical order you want to view all the notes)

  Εδώ ο χρήστης βλέπει όλες τις σημειώσεις του με χρονική σειρά βάση την επιλογή του στο σύστημα. Σε περίπτωση σφάλματος εμφανίζεται μήνυμα.
  
- /deleteAccount/(write your user name to delete your account)

  Εδώ ο χρήστης μπορεί να διαγράψει τον λογαριασμό του με βάση το username του στο σύστημα. Σε περίπτωση σφάλματος εμφανίζεται μήνυμα.
  
- /logout

  Εδώ ο χρήστης κάνει έξοδο από σύστημα. Σε περίπτωση σφάλματος εμφανίζεται μήνυμα.
  
- /newAdmin

  Εδώ κάποιος admin μπορεί να δημιουργήσει έναν νέο admin
  
- /changepassA

  Αυτό το url πρέπει να επισκεφθεί όποιο admin δεν έχει αλλάξει τον κωδικό πρόσβασης από την δημιουργία του. Εμφανίζεται κατάλληλο μήνυμα κατά την είσοδο εάν δεν εχει   γίνει αλλαγή

- /deleteUser/(write the username for the user you want to delete if you are admin)

  Εδώ οι admin μπορούν να διαγράψουν κάποιον χρήστη βάση το username του
  
  # How to run 
  
  Πρέπει να σετάρετε το docker ανάλογα το OS σας.
  
  Να έχετε python στον υπολογιστή σας και το postman
  
  Στα windows και mac το Docker Compose υπάρχει ήδη, οπότε γράφετε στο terminal στο path του φακέλου όπου έχετε τα αρχεία .py .yml και  Dockerfile
  
  docker compose up -d και για τερματισμό docker-compose down
  
  Για μεγαλύτερη ευκολία χρησιμοποιήστε το Docker Desktop το οποίο είναι ένα GUI για το Docker
  
  Όταν τρέξει το πρόγραμμα για πρώτη φορά θα δημιουργήσει έναν admin με email: admin@admin.com και password: admin
